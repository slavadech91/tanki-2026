# Сервер Tanki Online HTML5

Свой сервер для официального HTML5-клиента (`main.289a5d50.js`). Пакеты собирает кодек
`tools/proto_codec.py` по схеме `server-notes/proto_schema.json`; содержимое пространств берётся из шаблонов,
вырезанных из записи трафика.

Проверено в браузере: регистрация и повторный вход, конструктор танка, полное обучение, стартовые миссии
и отдельный локальный Deathmatch. Быстрый бой открывается из лобби после посещения категории «Обучение».

## Запуск
```bash
python server/main.py [http_port=8100] [ws_port=9100]
```
Игра: http://127.0.0.1:8100/play/.
- Клиент, шрифты страницы и ресурсы игры сервер один раз качает с `s.eu.tankionline.com` в `cache/` в корне
  репозитория (или в папку из переменной `TANKI_CACHE`). Картинки интерфейса и переводы клиент берёт с CDN сам.
- `?timer-raf` — для скрытой панели встроенного браузера: там не срабатывает `requestAnimationFrame`, и интерфейс
  клиента стоит на месте. С ключом кадры идут по таймеру (16 мс). В видимом окне ключ не нужен.

## Устройство
| файл | что делает |
|---|---|
| `main.py` | HTTP + WebSocket, сессии: управляющий сокет (HashRequest → HashResponse без шифра, `OpenSpace`), сокеты пространств |
| `protocol.py` | рамка пакета, управляющие команды, кодирование команд схемой |
| `spaces.py` | вход, конструктор, лобби, миссии, обучение и локальный Deathmatch |
| `tutorial_loadout.py` | сборка боевой комплектации из выбранных в конструкторе деталей |
| `accounts.py` | аккаунты в `server/data/accounts.json` (пароль — PBKDF2 с солью) |
| `web.py` | страница игры, `config.xml`, файлы клиента и ресурсы из кэша |
| `play.html` | своя страница: глобальные переменные, которые читает клиент, заглушки (Wake Lock, отчёты Sentry и аналитика остаются в браузере) |
| `templates/*.json` | пакеты пространств из записи трафика: `python tools/make_templates.py captures/session1.decoded.jsonl server/templates` |

Порядок пакетов и смысл команд: `server-notes/registration-to-tutorial.md`.

Шаблоны очищены от данных аккаунта, с которого записан трафик (это делает `make_templates.py`): ник заменён
на `%uid%` (сервер подставляет ник игрока), хэш «запомнить меня» — на `%hash%`, подписанный токен `state=` в
ссылке привязки Twitch удалён.

## Ограничения
- Все аккаунты получают id пользователя из записи (`0x2aaaaabafeae733a`): он зашит в шаблоны.
- Обучающий бой использует выбранные корпус, пушку и краску. Доступны «Хантер», «Викинг», «Диктатор»,
  а также совместимые с ними «Смоки», «Огнемёт», «Твинс» и «Рикошет». Остальные варианты скрыты до добавления
  боевых данных или превью. «Викинг» и «Диктатор» используют настройки движения, брони и овердрайва
  «Хантера» с размерами коллизий, подогнанными под их модели.
- После обучения можно войти под тем же аккаунтом по паролю или через «Запомнить меня». В лобби открываются категории «Обучение» и «Бонус за вход»,
  доступны награды за выполненные стартовые миссии.
- После посещения категории «Обучение» кнопка «Играть» открывает «Быстрый бой». Это локальный Deathmatch
  с пятью ботами на доступной учебной карте. Раунд заканчивается по истечении трёх минут или при восьми
  уничтожениях у одного участника. Сетевой матчмейкинг, другие боевые режимы и дальнейшая прогрессия
  миссий пока не реализованы.
