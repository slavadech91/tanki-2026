# Открытые вопросы (что нужно для сервера)

1. Формат пакета WebSocket: заголовок, длина, ID команды, XOR. Без этого клиент не подключится.
   ✅ Закрыто: рамка, NullMap, сжатие, шифр, дешифратор работает на всём захвате (protocol.md).
   Дальше: сопоставить ID методов (i64) с именами из бандла и разобрать аргументы кодеками.
2. Последовательность входа: что сервер шлёт после подключения (конфиг, ресурсы, пользователь, гараж).
   Частично известно: методы входа и хэши (auth.md). Не известны ID моделей/методов и порядок загрузки моделей.
   ✅ Порядок пакетов до лобби подтверждён повтором: клиент доходит до гаража (login-to-lobby.md).
   ✅ Формат `loadDependencies`/`loadObjectsData` разобран, пакеты генерируются кодеком (protocol-codecs.md).
   Дальше: собрать свои пространства из описания мира (JSON) вместо правки захвата.
3. Сопоставление ID команд ↔ имён методов (`_fire_*`, `_control_*`, …).
   ✅ Схема proto_schema.json: аргументы всех 681 входящих и 361 исходящего метода, 100% пакетов захвата
   декодируются и собираются обратно. Остались без имён исходящие методы и модели без CC (только ID).
4. Формат state/control команд танка и частота (`clientTickPeriodMs`).
   ✅ Формат `TankState` (23 байта битами) и методы — physics.md. i16 — номер появления ✅, i32 — время
   клиента в мс 🔎.
   ✅ В обучающем бою `clientTickPeriodMs = 300` (architecture.md).
5. Как клиент получает ID ресурсов танков и карт.
   ✅ Из `loadDependencies` (id, type, version); путь файлов — восьмеричные части id/version (resources.md).
6. Формат `map.bin` (геометрия и столкновения карты).
7. Параметры танков и пушек (скорость, масса, урон, перезарядка): что приходит с сервера.
   Частично ✅: приходят в CC объектов боя (`WeaponWeakeningCC`, `SimpleArmorCC`, …) и в `ItemPropertiesCC`
   гаража (weapons.md). Полный список CC обычного боя ещё не видели (в захвате только обучение).
8. Правила урона, критов, смерти и респавна (на сервере, восстанавливать по поведению).
9. Id и версии всех карт и 3D-моделей танков. В захвате session1 одна карта (обучение) и 35 моделей
   (resources.md, «Что есть в захвате»). Нужны новые захваты: бои на разных картах, предметы в гараже.
10. Состав обычного боя (DM/TDM): какие объекты и CC сервер шлёт вне обучения. Нужен захват обычного боя.
