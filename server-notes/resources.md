# Ресурсы и форматы

## Где лежат ✅
`https://s.eu.tankionline.com/<a>/<b>/<c>/<d>/<id>/<file>`. В каждой папке `meta.info`: JSON-список файлов
`{name, size, md5}`, текстуры в нескольких сжатиях (`*-astc.ktx`, `*-etc1.ktx`, `*-dxt.ktx`, `.webp`).
ID ресурсов клиент получает с сервера. Скачано: `tanki-assets/files/` (запись `tools/record_cdp.py`).

## Как клиент узнаёт ресурсы ✅ (protocol-codecs.md, `loadDependencies`)
- Список ресурсов приходит в `loadDependencies`: `{id: i64, type: i16, subType: i16, version: i64, isLazy, deps}`.
  В данных моделей ресурс — это просто i64 id (кодек `ds`), объект ресурса берётся из реестра по id.
- Путь файлов: `/resources/{id>>32}/{(id>>16)&0xFFFF}/{(id>>8)&0xFF}/{id&0xFF}/{version}/<файл>`, **все числа
  в восьмеричной записи**. Проверено: 837 ресурсов захвата лежат в `tanki-assets/files/` ровно по этим путям
  (остальные ленивые и не скачивались).
- Ленивые (`isLazy`) грузятся по требованию; ack `loadDependencies` клиент шлёт после не-ленивых.

## .a3d (модели) ✅ проверено на 78 файлах
Читалка: `tools/a3d.py`, экспорт в glb: `tools/a3d_export_all.py`. Little endian, строки = u32 длина + байты, выравнивание 4.
- Заголовок: `A3D\0`, u32 version=3, u32 ?, u32 длина тела. Дальше секции `[u32 тип, u32 размер, данные]`.
- 4 материалы: n × {имя, rgb f32×3, путь текстуры}.
- 2 меши: n × {имя, bbox f32×6, радиус, nverts, nattrs, атрибуты {тип, f32[nverts×w]}, nsub × {nidx, u16[]}}.
  Типы атрибутов: 1 позиция/3, 2 uv/2, 3 нормаль/3, 6 тангент?/3.
- 3 узлы: n × {имя, pos×3, quat xyzw, scale×3}, затем n × i32 родитель.
- 5 связи: {меш, узел, nmat, mat[]}; 0xFFFFFFFF = без материала.
- Версия 2 (меши эффектов) не разобрана.
- Ось Z вверх. Узлы корпуса: `hull`, `mount`, колёса `lwheel_*`/`rwheel_*`, `exh_*`; ховер: `lpropeller` и т. д.
