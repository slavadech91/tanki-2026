# Tanki Online HTML5 — заметки для своего сервера

Всё, что известно о механиках, физике, протоколе и данных клиента. Цель: собрать по этим заметкам свой сервер.

**Правило записи:** у каждого факта есть источник (строка/функция в бандле с позицией `@offset`, файл ресурса,
захват трафика) и статус:
- ✅ **проверено**: прочитан код или подтверждено трафиком / в игре
- 🔎 **по строкам**: выведено из имён и строк в бандле, код не прослежен
- ❓ **гипотеза**: предположение, проверить

Клиент: `tanki-src/main.289a5d50.js` (Kotlin/JS, минифицирован). Позиции `@N` относятся к этой версии;
имена вроде `d154_1` меняются от сборки к сборке, ориентироваться надо на строки.
В репозитории клиента нет: после первого запуска сервера он лежит в `cache/static/js/main.289a5d50.js`
(источник — `https://s.eu.tankionline.com/static/js/main.289a5d50.js`). `tanki-src/`, `tanki-assets/` и `captures/`
в заметках — локальные папки с клиентом, ресурсами игры и записями трафика; они не публикуются.
Поиск по бандлу: `python -I tools/js_find.py <bundle> <regex> [after] [before] [max]`,
строки: `python -I tools/js_strings.py <bundle> <regex>`.
